# Epic Seven 自动刷新商店 Bot — 开发进度

## 当前状态 (2026-05-21)

### 架构变更：坐标/颜色方案 → OCR 方案

**问题**：原有的坐标+颜色阈值方案效果较差：
- 物品分类靠 R/G 比值和色相猜，灯光/UI 一变就误判
- 价格识别用模板匹配，实际没加载过任何价格模板（assets/ 下有 55 张 unknown_*.png）
- 按钮检测用固定坐标+颜色，分辨率或布局变化全部失效

**解决方案**：全线替换为 RapidOCR（基于 ONNX Runtime，~1s/图 CPU）：
- 读物品名称原文（中文字符），按关键词匹配分类，不再猜颜色
- 读价格数字（"380,000" → 380000）
- 读按钮文字（"确认"/"取消"/"刷新"），直接点击文字坐标

### 待解决

1. **实机端到端验证**
   - OCR 方案尚未在 MuMu 模拟器上跑完整流程
   - 需要验证：物品识别 → 购买 → 刷新 链路

2. **RapidOCR 首次加载速度**
   - ONNX 模型加载约需数秒，不影响后续识别

3. **可能的优化**
   - 价格区域可加二值化预处理提高数字识别率
   - 对低置信度结果可以结合颜色辅助判断
