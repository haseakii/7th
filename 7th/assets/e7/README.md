## 校准指南

1. 将模拟器分辨率设置为 **1280×720**
2. 进入游戏对应界面，使用 ADB 截图：`adb exec-out screencap -p > screenshot.png`
3. 在截图中定位目标元素，记录其像素坐标 `(x1, y1, x2, y2)`
4. 裁剪目标元素区域保存为对应的模板 PNG 文件
5. 更新代码中对应 Button 的 `area`、`color`、`button` 坐标值
6. 对于物品模板（bookmark、mystic_medal、equipment、fodder），裁剪物品图标区域即可
7. 对于界面标识模板（lobby、shop_tab 等），选择该界面独有的特征区域

> **注意：** 不同模拟器、不同游戏版本的界面布局可能略有差异，建议每次游戏更新后重新校准坐标。
